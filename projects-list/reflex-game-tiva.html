Two-Player Reflex Game

Date: March 2026

Overview

Designed and implemented a two-player reflex competition game on the Tiva™ TM4C123GH6PM microcontroller using ARM Assembly. The system allows two players to compete by pressing buttons in response to a visual signal, with the fastest reaction determining the winner. The project integrates GPIO interrupts for real-time button detection and UART interrupt-driven communication to display instructions, game status, and scores through a serial terminal. This project demonstrates low-level hardware control, interrupt-driven programming, and structured assembly design for embedded systems.

Technologies & Tools

  • Tiva™ TM4C123GH6PM Microcontroller
  • ARM Assembly Language
  • GPIO Edge-Triggered Interrupts
  • UART Interrupt Communication
  • RGB LED Control
  • Embedded Systems Debugging

Key Features

  • Implemented real-time player input detection using GPIO edge-triggered interrupts, enabling immediate button response handling without continuous polling.
  • Developed an interrupt-driven UART interface to display game instructions, player prompts, and scores through the serial terminal, improving system responsiveness and user interaction.
  • Built a modular assembly architecture by organizing the program into reusable subroutines and a structured game loop, improving code clarity and maintainability.
  • Integrated RGB LED feedback to visually indicate game states such as waiting, ready, and winner, providing intuitive real-time feedback to players.
  • Implemented a two-player score tracking system using memory variables updated through interrupt events, allowing multiple rounds of gameplay.

What I Learned

Through this project, I developed a deeper understanding of interrupt-driven embedded programming and hardware-level system design. Working directly with microcontroller registers improved my ability to configure GPIO interrupts, manage UART communication, and debug low-level assembly code. I also learned how to design clear control flow using flowcharts and translate those designs into structured assembly subroutines for reliable real-time behavior.

Results

Successfully developed a fully functional reflex competition game capable of handling simultaneous input from two players using hardware interrupts. The system reliably detects button presses, manages game states, and updates player scores in real time. The project demonstrates strong foundations in embedded systems development, including interrupt handling, hardware interfacing, and low-level software design.
