TickTrek - Real-Time ARM Timer Game

A real-time interactive game on an ARM-based embedded system, featuring a 20x20 grid where a character navigates to collect points. Implemented using hardware timers and interrupts for dynamic gameplay.

Reflex Duel - Two-Player Reflex Game

A two-player reflex competition game on the Tiva™ TM4C123GH6PM microcontroller using ARM Assembly. Integrated UART communication, GPIO edge-triggered interrupts, RGB LED control, and real-time score tracking.
